# Setup Guide

## Prerequisites

- Windows 11 with 16GB RAM
- VMware Workstation or VirtualBox
- Ubuntu 22.04 ISO
- kubectl installed on master
- Git installed

## Step 1: Create Virtual Machines

| VM | CPU | RAM | Disk | IP |
|----|-----|-----|------|-----|
| master | 2 | 3.8GB | 50GB | 192.168.1.100 |
| worker | 2 | 4GB | 50GB | 192.168.1.101 |

## Step 2: Install Kubernetes

### On Both Nodes

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install containerd
sudo apt install -y containerd

# Configure containerd
sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
sudo systemctl restart containerd

# Disable swap
sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab

# Install kubeadm, kubelet, kubectl
sudo apt install -y apt-transport-https ca-certificates curl
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.30/DEB Release key.txt | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.30/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo apt update
sudo apt install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
```

### On Master Only

```bash
# Initialize cluster
sudo kubeadm init --pod-network-cidr=10.244.0.0/16

# Setup kubectl
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# Install Flannel CNI
kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml

# Allow scheduling on master (single-node lab)
kubectl taint nodes --all node-role.kubernetes.io/control-plane-
```

### On Worker Only

```bash
# Use the kubeadm join command from master output
sudo kubeadm join 192.168.1.100:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>
```

## Step 3: Install Infrastructure

### MetalLB

```bash
kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.13.10/config/manifests/metallb-native.yaml
kubectl apply -f kubernetes/infrastructure/metallb/
```

### Traefik

```bash
kubectl apply -f kubernetes/infrastructure/traefik/
```

### cert-manager

```bash
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.14.0/cert-manager.yaml
kubectl apply -f kubernetes/infrastructure/cert-manager/
```

### Monitoring

```bash
kubectl apply -f kubernetes/infrastructure/prometheus/
kubectl apply -f kubernetes/infrastructure/grafana/
```

## Step 4: Install Argo CD

```bash
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

## Step 5: Deploy Applications

```bash
# Apply root application (App of Apps)
kubectl apply -f argocd/applications.yaml
```

## Step 6: Configure DNS

Add to Windows hosts file (`C:\Windows\System32\drivers\etc\hosts`):

```
192.168.1.200 frontend.local
192.168.1.200 backend.local
192.168.1.200 argo.local
192.168.1.200 grafana.local
192.168.1.200 prometheus.local
```

## Step 7: Access Services

| Service | URL |
|---------|-----|
| Frontend | https://frontend.local |
| Backend | https://backend.local |
| Argo CD | https://argo.local |
| Grafana | https://grafana.local |
| Prometheus | https://prometheus.local |

## Argo CD Default Credentials

```
Username: admin
Password: <auto-generated>
```

Get the password:

```bash
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
```
